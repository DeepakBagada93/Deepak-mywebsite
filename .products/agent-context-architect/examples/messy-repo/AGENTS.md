# AGENTS.md

## Tooling

- Install with pnpm: `pnpm install`
- Run the suite with `pnpm run test`

## Style

- Use single quotes for all strings.
- Never use semicolons.
- Indent with tabs.
- Prefer named exports over default exports.
- Do not use `any` in TypeScript.

## Rules

- Never commit secrets or `.env` files.
- Do not add new dependencies without asking.
- Do not rewrite unrelated code while fixing a bug.
- Use descriptive variable names.

## Notes

The team is migrating package managers, so both npm and pnpm appear in older docs. New work should use pnpm.
