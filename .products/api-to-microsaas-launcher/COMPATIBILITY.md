# Compatibility Matrix: API to Micro-SaaS Launcher

**Version:** 1.0.0  
**Last Verified:** October 2026  

---

## 1. Supported AI Agent Environments
- **Google Antigravity (AGY)**: Native skill in `.agent/skills/`.
- **Anthropic Claude Code**: Terminal-driven generation in `CLAUDE.md`.
- **Cursor IDE**: Composer & agent workflows via `.cursorrules`.
- **OpenAI CLI**: System prompt injection.

---

## 2. Backend & Frontend Compatibility
- **Backend APIs**: Python FastAPI, Flask, Node.js Express, Go Gin, Rust Actix.
- **Frontend Stack**: Next.js 14/15 (App Router), React 19, Tailwind CSS.
- **Fintech & Billing**: Stripe Metered / Usage-Based Billing API.
- **Runtime**: Node.js 18.x, 20.x, 22.x, 25.x.
