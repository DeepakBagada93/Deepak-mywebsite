# Changelog

## [1.0.0] — 2026-10-18

### Added

- `workflow-hardener` skill: inventory, triage buckets, safe transforms, manual-fix specification, strict verification, handoff report.
- `audit-workflow.mjs`: 12 rule classes covering secrets, error handling, webhook auth, retries, timeouts, duplicate guards, pinned data, orphans, disabled nodes, duplicate names, execution order, and missing triggers.
- `harden-workflow.mjs`: retries, HTTP timeout, execution order, pinned-data removal; refuses to write when inline secrets exist.
- `verify-workflow.mjs`: CI gate with `--strict` mode and JSON output.
- Three fixtures: unsafe, half-hardened, and fully hardened reference; expected outputs generated by the scripts.
- Functional test suite covering detection, refusal, patch application, determinism, and directory mode.

### Known limitations

- Static analysis of exported JSON only; no live n8n import or execution was performed.
- n8n exports only; Make.com and Zapier schemas are rejected.
