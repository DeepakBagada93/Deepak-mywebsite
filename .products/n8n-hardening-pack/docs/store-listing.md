## The problem

Template bundles teach you to build workflows. They do not teach you what happens at 2 a.m.:

- The API call has no timeout, so the run hangs until the queue dies.
- The database insert has no retry, so one transient error drops the order.
- The webhook is unauthenticated, so anyone who finds the URL can write to your table.
- There is no error workflow, so failed runs disappear.
- Your export still contains pinned customer rows and an inline API key.
- A disabled node and an orphaned branch sit in the canvas, hiding what actually runs.

None of this shows up in a happy-path test. All of it shows up in support tickets.

## What it does

1. **Audit** — 12 rule classes across reliability, security, structure, and hygiene. Findings are deterministic and severity-ordered.
2. **Triage** — every finding lands in one of three buckets: safe to auto-fix, needs a human decision, or blocks all changes (inline secrets).
3. **Harden** — four narrowly scoped transforms: retries (3× / 1s), HTTP timeout (30s), `executionOrder: v1`, pinned-data removal. Nothing else is touched.
4. **Refuse** — if credentials are inlined, the hardener stops and tells you exactly how to migrate them to n8n credentials. It never masks or rewrites a secret.
5. **Gate** — `verify-workflow.mjs` exits 1 on critical/high findings, or on medium too with `--strict`.

## FAQ

**Does it need an n8n instance or API key?**
No. It reads the exported JSON. No network calls.

**Does it fix my hardcoded API key?**
No — and that is deliberate. It refuses to run and tells you how to move the value into an n8n credential. Masking a live key in a JSON file would make the audit lie.

**Will the hardened file import cleanly?**
The schema and node set are preserved, and only node fields listed in the transform table are added. **Import into a live n8n instance was not executed during build**, so this is disclosed as untested rather than promised. Reattach credentials after import.

**Which n8n versions?**
Rules target common export shapes from n8n 1.x. Version-specific parameter changes may produce no finding rather than a false pass. Community nodes are audited structurally only.

**Is the score a security certification?**
No. It is a checklist score for known failure modes. It is not a penetration test or a compliance audit.

**Can I use it on client workflows?**
