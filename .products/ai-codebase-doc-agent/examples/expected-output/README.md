# Sample Python API

> A FastAPI-based REST API for user management and order processing with payment integration.

## Quick Start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Copy environment config
cp .env.example .env

# 3. Run the server
uvicorn src.main:app --reload

# 4. Open API docs
open http://localhost:8000/docs
```

## Architecture

The application follows a **layered architecture**:

```
Client Request → Router (routes/) → Service (services/) → Model (models/)
                        │
                        ▼
                  Configuration (config.py)
                        │
                        ▼
                  FastAPI App (main.py)
```

### Key Components

| Component | Role | File |
|-----------|------|------|
| **FastAPI App** | Entry point, middleware, router registration | `src/main.py` |
| **Config** | Environment-based settings | `src/config.py` |
| **User Model** | Pydantic schemas for user data | `src/models/user.py` |
| **Order Model** | Pydantic schemas for order data | `src/models/order.py` |
| **User Routes** | User CRUD (list, create, get, update, delete) | `src/routes/users.py` |
| **Order Routes** | Order management (list, create, status update) | `src/routes/orders.py` |
| **Auth Service** | JWT authentication | `src/services/auth.py` |
| **Payment Service** | Payment processing | `src/services/payments.py` |

### Data Flow

1. Client sends HTTP request to FastAPI endpoint
2. Router validates input using Pydantic models
3. Service layer handles business logic (auth, payment)
4. Response is returned using Pydantic models for serialization

## API Endpoints
