## [1.0.0] - 2026-10-28

### Added
- **Repository Context Builder CLI (`scripts/context-builder.mjs`)**:
  - Standalone Node.js tool to detect framework versions (Next.js 14/15, React 19, Tailwind v3/v4, Prisma/Drizzle).
  - Deterministic generation of token-dense architectural rules.
- **Multi-Client AI Agent Skill (`skills/context-engine/SKILL.md`)**:
  - 3-Phase protocol for stack discovery, guardrail synthesis, and multi-IDE distribution.
- **Reference Example (`examples/react-nextjs-repo/`)**:
  - Full-stack package.json and verified `.cursorrules` / `CLAUDE.md` outputs.
- **Documentation & Storefront**:
  - `docs/tutorial-guide.md`: Quickstart, multi-IDE setup, and prompt recipes.
  - `docs/store-listing.md`: Direct-response storefront copy with dual pricing ($49/₹999 Solo; $99/₹2,499 Team).
