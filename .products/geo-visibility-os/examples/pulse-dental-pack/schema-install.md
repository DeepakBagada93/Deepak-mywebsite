# Schema install

1. Paste Organization into the sitewide head or the home page template.
2. Paste Service on the primary service page and keep the name identical to the visible service.
3. Paste FAQPage only after the same questions and answers are visible on the page.
4. Paste BreadcrumbList on the service and comparison pages.
5. Paste Article on each content brief page and keep the author consistent with the visible byline.
6. Validate every block before deploy and re-scan after deploy.

Validate every block before deploy, then re-scan the live page. Schema that does not match visible content is a risk, not a win.
