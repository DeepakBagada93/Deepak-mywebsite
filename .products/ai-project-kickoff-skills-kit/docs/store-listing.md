## Description

Deepak Bagada Systems’ AI Project Kickoff Skills Kit gives solo founders and AI developers two reusable planning skills: one to clarify scope and risks, and one to turn an accepted brief into milestones with test evidence. It is a Markdown skill bundle for manual loading in a compatible AI coding-agent workflow.

## Included

Two skills, a project-brief template, one end-to-end SaaS planning example, testing checklist, compatibility notes, and setup documentation.

## Requirements and compatibility

Requires an AI agent that can be given Markdown instructions manually. Auto-discovery and native compatibility for Claude Code and Gemini CLI are not tested. No API key is included or required by this package.

## Example use

Start with a support-theme dashboard idea, define an MVP that uses CSV import and human review, then turn it into staged implementation work while preserving exclusions around OAuth and automated support actions.

## FAQ and limitations

**Does it build my app?** No; it produces a project brief and implementation plan. **Does it validate demand or compliance?** No; those require separate evidence and review. **Can I redistribute it?** Commercial licensing awaits owner approval.
