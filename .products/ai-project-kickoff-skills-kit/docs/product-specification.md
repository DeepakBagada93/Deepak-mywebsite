# Product specification

## Positioning

AI Project Kickoff Skills Kit helps solo founders and AI developers turn ambiguous software ideas into scoped, testable plans before coding.

## Included and excluded

Included: two reusable Markdown skills, brief template, end-to-end example, structural test, installation and troubleshooting documentation. Excluded: automatic client installation, product research, code generation, integrations, hosting, or guaranteed project outcomes.

## Acceptance evidence

Both skills have valid frontmatter and actionable flows; the SaaS example demonstrates discovery-to-plan handoff; validation and structural test results are retained in `test-results.md`.

## Commercial notes

Price and commercial terms remain hypotheses requiring owner approval. Support is documentation-led; compatibility beyond manually loaded Markdown skills is untested.
