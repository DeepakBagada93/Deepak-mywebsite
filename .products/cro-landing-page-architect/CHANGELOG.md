All notable changes to this commercial AI skill product will be documented in this file.

## [1.0.0] - 2026-10-28

### Added
- **10-Dimension CRO Audit CLI (`scripts/cro-audit.mjs`)**:
  - Standalone Node.js tool to evaluate landing page conversion readiness (0–100%).
- **Autonomous CRO AI Agent Skill (`skills/cro-architect/SKILL.md`)**:
  - 4-Phase conversion protocol covering diagnostic audit, hero rewrite, objection-killing FAQ, and responsive Tailwind UI.
- **Reference Benchmarks (`examples/saas-landing-page/`)**:
  - Comparison of low-converting 20% baseline vs 100% green high-converting landing page.
- **Customer Documentation & Storefront**:
  - `docs/tutorial-guide.md`: Quickstart, prompt recipes, and CRO checklist.
  - `docs/store-listing.md`: Direct-response storefront copy with dual pricing ($59/₹1,299 Solo; $129/₹3,299 Studio).
