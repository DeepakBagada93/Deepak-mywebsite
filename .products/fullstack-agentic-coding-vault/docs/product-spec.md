# Product Specification: Full-Stack AI Coding Guardrails & Skill Pack

## Overview
A drop-in suite of agent rules, skill manifests, and architectural enforcement files designed to turn any AI coding assistant into a disciplined senior full-stack engineer.

## Deliverables Specification
1. **`skills/fullstack-agentic-coding-vault/SKILL.md`:** Claude Code / Antigravity compatible skill manifest with progressive disclosure triggers.
2. **`rules/nextjs-fullstack-guardrails.mdc`:** Next.js 14/15 App Router, React Server Component, and Server Action rules.
3. **`rules/clean-architecture-tdd.mdc`:** Repository pattern isolation and automated test-first verification guardrails.
4. **`rules/database-safety-migrations.mdc`:** Anti-destructive SQL/ORM safeguards.
